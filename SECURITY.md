# Segurança e conteúdo público

Este repositório se destina a arquivos públicos. Nunca adicione credenciais, tokens, chaves privadas, documentação interna de manuscritos ou dados pessoais de leitores.

A privacidade do código não impede que os arquivos enviados ao navegador sejam lidos. Remova spoilers e conteúdo confidencial da versão entregue ao público, em vez de apenas ocultá-los na interface.

Para reportar problemas sensíveis, contate o mantenedor por um canal privado (a definir). Não publique senhas ou dados de terceiros em issues públicas.
